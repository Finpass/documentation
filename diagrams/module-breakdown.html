Module 01

Financial profiling engine

Five steps from answers to a profile, a target mix, matched products and a plain-language explanation. Output: profile and recommended mix.

Core rules

  • Steps 2-4 are pure code: no AI is involved in who gets which profile or product.
  • Step 5 is the only model call, and it is wrapped by a guardrail and a template fallback.
  • Every step writes a trace (rule, value, excluded assets) kept as an audit record.

Module 02

Dashboard with financial advisory chat

Steps 1-2 are arithmetic on the user's data; steps 3-5 are the chatbot's retrieval-augmented pipeline. Output: cited advisory answers.

Core rules

  • The chat receives the same profile, holdings and rule results the dashboard shows, so answers and screens never disagree.
  • Retrieval is dense search plus a cross-encoder rerank; there is no keyword index.
  • A guardrail failure twice returns source excerpts rather than an unchecked answer.

Module 03

Personalized daily briefing

From a per-user timer to a WhatsApp message and back through reply commands. Output: daily WhatsApp briefing.

Core rules

  • Sending is idempotent: a double tick or a second server instance cannot send the same briefing twice.
  • The briefing is plain templates over numbers decided by rules; no LLM writes it.
  • STOP opts the user out immediately; RESUME opts back in.
